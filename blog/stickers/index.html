Стикеры по клику
на Тильда

Хотите добавить разнообразия и динамики сайту? Делюсь пошаговой инструкцией для анимации ваших стикеров по клику на Тильда.

Любовь Русанова

Автор статьи, веб и графический дизайнер

В этой статье

Перед началом1. Область для стикеров2. Добавляем код3. Ваши изображения4. Публикуем и проверяем

Перед началом

Начну с того, что эту модификацию я увидела на этом сайте, но, к сожалению, с кодом из той инструкции у меня ничего не вышло. Поэтому решила сделать всё сама с помощью нейросети Perplexity.

!

Код не подходит для автоскейла.
В блоке, где вы хотите сделать такую анимацию, лучше его не использовать.

Шаг 1

Создаём область
для стикеров

Создайте шейп — область, в которой будет анимация. Нажмите на него правой кнопкой мыши и добавьте CSS-класс stickers.

Чтобы анимация не конфликтовала с остальными элементами, создайте отдельный прозрачный шейп. Важные элементы — кнопки, текст и формы — разместите поверх него, а второстепенные и некликабельные оставьте под ним.

Шаг 2

Добавляем код

Ниже Zero-блока добавьте HTML-блок T123 и вставьте в него код.

Код для блока T123
<script>
document.addEventListener("DOMContentLoaded", function () {
  // Массив ссылок на один или несколько стикеров
  const STICKER_SRCS = [
    "https://static.tildacdn.com/tild3063-6565-4333-b738-373264323931/photo.png"
  ];

  const area = document.querySelector(".stickers");
  if (!area) return;

  area.style.position = area.style.position || "relative";
  area.style.overflow = "hidden";

  area.addEventListener("click", function (e) {
    const rect = area.getBoundingClientRect();
    const x = e.clientX - rect.left;
    const y = e.clientY - rect.top;
    const img = document.createElement("img");

    // Выбор случайного стикера из массива
    const randomIndex = Math.floor(Math.random() * STICKER_SRCS.length);
    img.src = STICKER_SRCS[randomIndex];
    img.alt = "";
    img.loading = "lazy";
    img.style.maxWidth = "120px";
    img.style.width = "120px";
    img.style.height = "auto";
    img.style.position = "absolute";
    img.style.pointerEvents = "none";
    img.style.zIndex = "999999";
    img.style.transform = "scale(0.3)";
    img.style.opacity = "0";
    img.style.transition = "transform 0.25s ease, opacity 0.25s ease";
    area.appendChild(img);

    const w = img.offsetWidth;
    const h = img.offsetHeight;
    img.style.left = (x - w / 2) + "px";
    img.style.top = (y - h / 2) + "px";

    requestAnimationFrame(function () {
      img.style.transform = "scale(1)";
      img.style.opacity = "1";
    });

    setTimeout(function () {
      img.style.transform = "scale(0.3)";
      img.style.opacity = "0";
      setTimeout(function () {
        img.remove();
      }, 250);
    }, 1000);
  });
});
</script>

Шаг 3

Подставляем
свои изображения

Один стикер

Замените ссылку на изображение внутри кавычек в массиве STICKER_SRCS на свою.

const STICKER_SRCS = [
  "ССЫЛКА_НА_СТИКЕР"
];

Несколько стикеров

Вставьте ссылки на изображения через запятую. Каждая ссылка должна оставаться внутри кавычек.

const STICKER_SRCS = [
  "ССЫЛКА_НА_ПЕРВЫЙ_СТИКЕР",
  "ССЫЛКА_НА_ВТОРОЙ_СТИКЕР",
  "ССЫЛКА_НА_ТРЕТИЙ_СТИКЕР"
];

Для вставки изображений в код я сначала перемещаю их в Zero-блок, нажимаю правой кнопкой мыши и копирую URL изображения.

Шаг 4

Публикуем
и проверяем!

Опубликуйте страницу и попробуйте нажать на область со стикерами.

Что важно учитывать

  • HTML-блок должен быть ниже Zero-блока.
  • CSS-класс должен совпадать полностью и быть назначен только на один шейп в блоке.
  • Проверьте запятые, структуру кода, кавычки и закрывающий тег </script>.

Не судите строго! Код написан с помощью нейросети и меня, которая пока совсем мало знает в разработке ♥
